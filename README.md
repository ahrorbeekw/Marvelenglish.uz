# 📖 About

Marvel English is a modern landing page developed for a real English Learning Center.

The goal of this project was to create a premium-looking website that introduces the learning center, teachers, student achievements, and community while encouraging visitors to enroll.

### Key Highlights

- Modern UI/UX
- Responsive Design
- Fast Performance
- Smooth Animations
- Clean Layout
- High-Converting Landing Page
