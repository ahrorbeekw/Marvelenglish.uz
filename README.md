# About

Marvel English is a modern landing page developed for a real English Learning Center.

The goal of the project was to create a premium-looking website that introduces the learning center, teachers, student achievements, and community while encouraging visitors to enroll.

The website focuses on:

- Modern UI/UX
- Responsive Design
- Fast Performance
- Smooth Animations
- Clean Layout
- High Conversion Landing Page
